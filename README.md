# 页间写作室 · IELTS Writing Studio

一个在自己电脑上运行的雅思学术类写作练习网站。你可以对照题目和图表写作文，交卷后回放自己的删改过程，把批改中值得学的表达加入复习，再根据历次原稿和修改稿决定下一篇写什么。

## 快速开始

下载或克隆本仓库，进入包含 `server.py` 的目录。需要 **Python 3.9 或更高版本**。后端使用 Python 标准库和 SQLite，前端是原生 HTML、CSS 和 JavaScript，下载源码后即可启动。

| 系统 | 启动方式 |
| --- | --- |
| Windows | 双击 `start-windows.cmd`，或在 PowerShell 运行 `.\start-windows.cmd` |
| Linux | 在终端运行 `sh start-linux.sh` |
| macOS | 双击 `启动写作室.command`，或在终端运行 `python3 server.py` |

保持终端窗口开启，在浏览器打开 [本机写作室](http://127.0.0.1:8767/)。第一次使用，可以先到「写作题库」选一道题开始写。计时、保存和回放都可以直接使用；需要 AI 批改时，再到「工作室设置」选择模型。

## 可以怎么练

| 你想做什么 | 网站里的入口和功能 |
| --- | --- |
| 模拟考试或单练一题 | 「工作台」提供 60 分钟完整模考，到时交卷。「写作题库」里的专项练习从零正计时，支持暂停、继续和超时后手动交卷。 |
| 看自己写作时改了什么 | 「写作记录」保留原稿和各次重写。本站编辑器记录的输入、粘贴和删改可以倍速回放，也可以跳过空闲时段。 |
| 看懂一篇作文的反馈 | 批改报告把作答题目、四项教学估分、拼写与语法纠错、逐句彩色批注和提升版范文放在一起。词汇提升会解释何时适合换词，并给出搭配和例句。 |
| 把学过的表达用出来 | 在报告中收藏词句，用内置 FSRS 做今日复习，或在自由练习组合筛选熟悉度、任务、题型、话题和作文日期，勾选想练的项目。可快速翻看、根据整句中文完成英文挖空，或进行回译。模型可生成新语境，所选卡片也可导出为带「雅思作文 → Task 1 或 Task 2 → 来源作文」牌组的 Anki 文本。 |
| 决定下一篇写什么 | 「写作计划」分别推荐 Task 1 和 Task 2。可以查看推荐依据、按题型或话题对照剑雅频次与自己的练习次数、回看上次练习日期，也可以指定题型让 AI 出原创题。话题留空时随机选择。 |

题库索引覆盖剑雅学术类 C1–C21 共 **84 套、168 道任务**。在「工作室设置 → 剑雅题库」可选本地或联网模式。选择本地时服务会后台补全缺项，之后可离线练习。联网模式优先读取源站并标注回退到本机副本的情况。源站要求浏览器验证时，可以自行打开题源并贴入英文原文、附上题图。设置里能查看题文与配图数量，可导出可读的题文 Markdown，也可用独立题库包在自己的设备之间迁移。官方样题直接打开 IELTS 的在线 PDF 对应页。四套原创模考可离线使用。练习全景中的百分比以选定册次的样本题数为分母，每道题可以涉及多个话题。

## AI 接入

- **本机 Codex**：先在运行网站的电脑上安装并登录 Codex CLI，再在设置中选择 Codex，可用于批改、分析选题和生成练习。
- **兼容 API**：在设置中填写 Base URL、模型 ID 和所需的 API Key。服务须支持 Chat Completions 和 JSON 输出；批改带原图的题目时，还需要模型支持图像输入。
- **外部智能体**：其他软件可以使用本机令牌读取待批改任务，并通过接口提交结构化报告。认证、请求示例和报告格式见[智能体接入手册](智能体接入手册.md)。

学习记录保存在本机。调用模型时，写作室会把完成该任务所需的内容交给所选服务，例如批改用的作文、题目和编辑过程证据。

## 个人数据与备份

首次启动会在当前系统用户的数据目录中创建数据库，作文和报告另有可阅读的 Markdown 归档。默认位置如下。

| 系统 | 默认个人数据目录 |
| --- | --- |
| Windows | `%LOCALAPPDATA%\IELTS Studio` |
| Linux | `$XDG_DATA_HOME/ielts-studio`，未设置时使用 `~/.local/share/ielts-studio` |
| macOS | `~/Library/Application Support/页间写作室` |

在「工作室设置」中可以迁移数据目录、导出或恢复学习备份，也可以在启动前设置环境变量 `IELTS_DATA` 指定目录。服务默认仅监听本机地址，远程 Linux 使用方式见[智能体接入手册](智能体接入手册.md#远程-linux-主机)。

**将代码发布到 GitHub 时，请把个人数据目录、导出的作文 Markdown 和含真实记录的截图放在仓库外。** 项目的 [.gitignore](.gitignore) 已覆盖 SQLite 数据库、模型配置、智能体令牌、ZIP 备份和默认命名的 Anki 导出。提交前可用 `git diff --cached --name-only` 核对实际暂存的文件。
